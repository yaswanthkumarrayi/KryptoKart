# KryptoKart backend

Express + MongoDB API for the `billing_fixed` Flutter app.

## Run

```bash
npm install
npm start
```

- Health: `GET /health`
- API: `/api/...` (see route files in `routes/`)

## Docs

Repo-root [BACKEND_DOCUMENTATION.md](../BACKEND_DOCUMENTATION.md) and [README_COMPREHENSIVE.md](../README_COMPREHENSIVE.md) describe setup and endpoints. **Source of truth** for behaviour is the JavaScript in `routes/` and `models/`.
